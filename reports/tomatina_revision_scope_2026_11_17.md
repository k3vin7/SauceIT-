# 토마티나 수정 범위 — 2026-11-17

사용자 확정 사항. 번호는 대화의 43개 검토 항목과 대응한다.

- 작업 대상은 스테이지 2 토마티나. 스테이지 1 레벨과 콘텐츠는 수정하지 않는다.
- 현상 유지: 1(소스 기본 위험/보상 규칙), 5(장비 역할 재설계), 7(시작 흐름), 16(사망 보급), 30(HUD 슬롯 구성).
- 나중: 4 및 18~23(스테이지 1 보완), 6(친구 초대/릴레이 접속), 9(호스트 이전/재접속).
- 2: 연속 넘어짐/감속/밀침/시야 방해의 중첩 완화.
- 3: 폭발 적과 작은 적을 크게 늘려 연쇄 폭발 쾌감 강화. 새 마요 전술 규칙은 추가하지 않음.
- 8: 진행 중 참가, 안전지점 합류. 10: 빠른 재시도/다음 임무.
- 11: 막힘/압력/저잔량 규칙 유지. 박사가 마우스 흔들기로 막힘을 풀도록 안내.
- 12: 유효 거리 조준점 색/빛만. 착탄 지점 표시는 금지. 투척물은 포물선 궤적 표시.
- 13: 바닥 위험 가독성. 14: 마우스 흔들기만 유지, 효과 잔여 시간 표시. 대체 입력 추가 금지.
- 15: 상호작용 대상 안정화. 17: 부활 시 고글 세척.
- 24~29: 협동 난이도/공격 예산, 보스 연속 피격 완화, 구조 대기 개선, 조작표 오류, 튜토리얼 보급 안내, 체력바 가림.
- 31: L4D2처럼 임무 종료 후 참가자별 통계.
- 32~38: 옵션, 메뉴/실제 정지, 토마티나 미술 통일, 1인칭 장비, 오염 가독성, 소리 우선순위, 끊김 계측.
- 39: 성능/부하/장시간/4인 벤치마크는 실행 직전에 사용자에게 여부를 묻고 답을 기다린다. 승인 없이 실행하지 않는다.
- 40~43: 이동 예측/서버 보정, 즉각적인 시각 반응과 확정 판정 분리, 작업 영역 분리, 플레이테스트 항목과 근거 기록.

## 검증 구분

구문/기능 회귀 검사는 개발 검증이다. 39번의 FPS 측정, 부하/장시간 플레이, 성능 벤치마크와 실제 사용자 플레이테스트는 별도 승인/참여가 필요하다. 실행하지 않은 검증을 완료로 기록하지 않는다.
