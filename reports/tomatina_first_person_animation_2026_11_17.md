# 토마티나 1인칭 실제 애니메이션과 HUD

## 최신 사용자 수정

- 대기 및 제자리 발사에서는 손·소스통을 고정한다. idle 호흡, 발사 시작/유지/종료 클립과 기존 로컬 분사 반동·무작위 노즐 흔들림을 재생하지 않는다.
- 자동 흔들림은 지면에서 걷거나 달릴 때만 적용한다. 정지·점프·공중·착지에서는 이동 애니메이션과 관성을 초기화한다.
- 직접 소스통을 흔들어 막힘을 해결하는 동작과 그 복귀, 장비를 꺼내는 동작은 유지한다. 이동 중 사격에는 보행 흔들림만 적용한다.
- 수정된 VIEWMODEL_ANIMATION_OK 및 VIEWMODEL_INERTIA_OK 검사 통과. 아래 12개 클립 제작 설명과 기존 GIF는 이전 동작의 기록이며 현재 자동 재생 범위를 의미하지 않는다.

## 애니메이션

관성에 더해 Godot AnimationLibrary의 키프레임 클립 12개를 제작했다. tools/build_viewmodel_animations.gd로 assets/players/first_person/movement.tres를 재생성할 수 있다. Blender 캐릭터 리그나 모델을 수정한 작업은 아니다.

- idle / walk / run: 호흡과 좌우 보행 주기, 달리기 때 낮아지는 자세.
- fire_start / fire_loop / fire_stop: 발사 시작의 짧은 밀림, 지속 분사 진동, 종료 후 복귀.
- shake_start / shake_loop / recover: 준비, 반복 펌핑과 손목 회전, 동작 종료의 후속 움직임.
- jump / air / land: 이륙 지연, 공중 유지, 착지 눌림과 반동 복귀.

이동과 소스통 동작은 각각 AnimationPlayer에서 동시에 재생된다. 기존 마우스 흔들기 입력과 소스통 세우기, 물리 반동은 유지한다. 손과 소스통은 같은 시각 변환을 사용하며, 팔꿈치는 손의 변위를 일부 따라가고 손가락 방향은 소스통 회전을 따른다. 애니메이션 트랙은 시각 노드의 position/rotation만 포함하며 카메라·조준·충돌·서버 발사 위치를 변경하지 않는다. 화면 흔들림 설정을 적용하고 메뉴·다운·3인칭에서는 초기화한다.

## HUD

- 토마티나 다인 팀 상태를 목표 아래 반투명 패널로 표시한다. P1~P4, 본인 번호 민트색, 체력바·체력·소스 잔량을 일정한 열에 정렬한다. 봇 상태 문장 목록은 제거하고 F6 상태만 패널 하단에 둔다.
- 기존 다섯 슬롯을 유지하면서 선택 슬롯에 민트 테두리/하단 표시를 추가했다.
- 개인 체력/소스 막대를 두껍게 하고 저잔량 소스를 노란색으로 표시했다. 하단 안내와 상태창 사이 간격 및 가장자리 여백을 확보했다. 강화 유지시간 표시는 기존 소스 패널에 유지한다.
- 조준점 외곽선과 유효 사거리 중심점의 대비를 강화했다. 착탄점 표시는 추가하지 않았다.
- 광장으로 이동 중에는 이동 목표만, 광장 도착 후에는 발전기 작동 목표를 표시한다.

## 검증

- VIEWMODEL_ANIMATION_OK: 이동/달리기/분사/흔들기/점프/공중/착지 전환, 두 레이어 동시 재생, 루프 경계와 단발 복귀, 비활성 초기화.
- VIEWMODEL_INERTIA_OK 및 PLAYER_BOTS_OK 통과.
- 실제 렌더러에서 6개 대표 동작의 프레임을 캡처하고 확인했다. reports/viewmodel_animation_sheet.png, viewmodel_animation_preview.gif는 포즈/클립 미리보기이며 자동 플레이나 성능 측정이 아니다.
- 새 손 모델/스킨 리깅은 만들지 않았다. 기존 1인칭 손의 형태는 유지한다. 전체 스테이지 완주와 실제 사람의 조작감 평가는 이번 검증에 포함되지 않는다.
