# 토마티나 플레이어 봇

## 사용법

타이틀의 **봇 3명과 토마티나 연습**을 누르면 사람이 조작하는 리더 1명과 봇 3명이 참가한다. **F6**으로 리더도 자동 조작하게 하거나 다시 직접 조작할 수 있다. Esc 메뉴와 임무 종료 통계/재시도는 기존 흐름을 사용한다.

## 행동과 한계

- 실제 플레이어 캐릭터의 이동 입력·조준·발사·마우스 흔들기 입력 세기·닦기·보급·구조·밀치기·호스 상호작용을 사용한다.
- 피해를 직접 적용하거나 체력/소스를 임의 충전하지 않는다. 막힘을 순간이동이나 적 삭제로 해결하지 않는다.
- 동료를 따라가고 대형을 유지하며, 보이는 적을 고르고 아군이 사선에 있으면 발사를 멈춘다. 회전 속도와 반응 주기, 작은 조준 오차가 있다.
- 폭발 예고 범위에서 달아나고, 실제 캐릭터 충돌 검사로 막힌 이동 방향을 피하며, 접근 불가능한 적은 잠시 다른 대상으로 바꾼다. 큰 적의 몸 중심 대신 주변의 사격 위치로 길을 찾는다.
- 낮은 잔량이면 보급 장소로 이동하고, 고글이 오염되면 닦고, 가까운 다운 동료를 구조한다.
- 회복 토마토도 실제로 주워 인벤토리에 넣고 먹는다. 가까운 보급소라도 경로가 없으면 다른 도달 가능한 보급소를 찾는다.
- 자동 리더는 알려진 맵 경로를 따라 안전지점에 집결하고 발전기를 작동시킨다. 피날레에는 호스 담당과 방어 담당을 나누고 보스 처치 후 탈출을 시도한다.
- 길 찾기는 게임의 보행 격자를 사용한다. 따라서 초보자가 길을 찾는 능력을 재현하지 않는다. 길에 걸리면 점프/재탐색을 시도하고 기록한다.
- 전투 중 지나간 경로 지점은 통과로 처리하되, 안전지점은 실제 팀 집결로 체크포인트가 확정되어야 다음 구역으로 넘어간다.
- 한 PC의 오프라인 월드 안에서 4캐릭터를 조작한다. 독립된 네트워크 클라이언트 4개나 실제 사람 4명의 검증이 아니다.
- 결정 규칙을 따르는 게임 봇이며, 캐릭터마다 별도의 대화형 AI 모델이 실행되는 방식은 아니다.

## 관찰 실행

tests/play_tomatina_bots.gd는 기본 120초의 4봇 자동 플레이를 수행한다. 실행 종료 시 reports/tomatina_bot_play.json에 이동 거리, 발사 시간, 보급/구조 시도, 다운, 경로 정체와 임무 통계를 남기고, 화면이 있는 실행에서는 PNG 한 장을 저장한다.

FPS나 부하 수치는 수집하지 않는다. 성능 벤치마크를 함께 수행하려면 기존 규칙대로 실행 직전에 별도 승인을 받아야 한다.

## 확인된 결과와 제한

- PLAYER_BOTS_OK: 4캐릭터 구성, 인간 리더 입력 유지, 자동 리더 입력 전환, 메뉴 중 봇 입력 정지, 보고서 생성.
- PLAYER_BOTS_APP_OK: 타이틀 진입, 토마티나 선택, 솔로 일시 정지/재개, 결과 통계, 재시도, 타이틀 복귀.
- 첫 120초 관찰: 총 69마리 처치, 실제 구조 11회, 보급 5회. 경로 3/43 지점, 미클리어. 초안의 보급/접근 경로 문제가 드러났다.
- 회피/회복을 보완한 두 번째 120초 관찰: 총 53마리 처치, 다운 1회, 회복 토마토 사용 5회, 보급 3회. 네 명이 서 있는 상태로 종료했으나 경로 3/43 지점에서 전투/경로 정체가 남았다.
- 무작위 드롭과 봇 행동이 달라진 관찰이므로 두 실행을 사람의 난이도나 성능 개선 증거로 사용하지 않는다.
- 아직 전체 스테이지 완주를 확인하지 못했다. 보스/호스/탈출 행동은 구현되어 있으나 실제 도달 검증은 남아 있다. 특히 복잡한 장애물 주변 길 찾기와 밀집 전투 사선 조정은 초기 수준이다.
- 세 번째 관찰에서 전투 중 이미 앞으로 이동했는데 경로 지점으로 되돌아가는 문제가 확인되어, 관찰 좌표를 사용하는 기능 회귀 검사를 추가하고 통과 인식 로직을 수정했다. 회귀 검사의 위치 설정은 테스트용 재현이며 실제 자동 플레이에는 순간이동을 사용하지 않는다.
- 최종 수정 후 90초 관찰: 59마리 처치(특수 적 4마리 포함), 폭발 처치 18회, 보급 5회, 회복 1회. 다운 없이 네 명 모두 서 있는 상태로 종료. 경로 4/43까지 진행했고 no_route 기록은 0회. 이 실행에서도 스테이지 완주는 하지 않았다. 직전 실행들과 무작위 결과가 다르므로 난이도 개선의 정량 증거로 사용하지 않는다.
