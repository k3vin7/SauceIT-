# Sauce prototype foley

Original procedural mono PCM clips, generated by `tools/generate_sauce_audio.py` (Python standard library; no external samples).

- `start` / `spray_loop` / `end`: squeeze onset, continuous nozzle flow, release.
- `contact`: first contact and stronger threshold accents.
- `contact_loop`: lower, denser liquid texture while landing on a live enemy.
- `splat_1..3`: randomized sustained impacts.
- `defeat`: longer, lower impact for the collapse.

These are prototype sounds intended for later replacement with recorded liquid/foley. Godot configures loop points on per-world copies of the loop resources. `M` mutes all audio. Rebuild with `python3 tools/generate_sauce_audio.py`, then reimport in Godot.
