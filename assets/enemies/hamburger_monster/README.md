# Hamburger monster asset

`hamburger_monster.glb` is exported from the user-supplied
`Stage1_HamburgerMonster.blend` with Blender 5.2, Y-up conversion, and all
actions enabled. The runtime binds the imported `Idle`, `Walk`, `Attack`, and
`Death` actions by suffix so Blender's stage-prefixed action names remain the
source of truth.
